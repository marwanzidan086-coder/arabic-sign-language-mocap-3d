# Contributing to Arabic Sign Language & 3D MoCap AI System 🤟

Thank you for your interest in contributing to the **Arabic Sign Language & 3D MoCap AI System**! We welcome contributions from developers, researchers, 3D artists, and accessibility advocates worldwide.

---

## 🌟 How Can You Help?

1. **AI & Gesture Recognition Models**: Expanding the Arabic Sign Language dataset, optimizing classification algorithms, and refining kinematics.
2. **3D Avatars & Graphics**: Creating realistic VRM avatars, custom animations, shader improvements, and lighting presets in Three.js.
3. **Accessibility & UI/UX**: Making the web interface even more accessible for the Deaf and Hard-of-Hearing community.
4. **Bug Reports & Feature Ideas**: Opening descriptive GitHub Issues.

---

## 🚀 Development Workflow

1. **Fork the Repository**
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/arabic-sign-language-mocap-3d.git
   cd arabic-sign-language-mocap-3d
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make and Test Your Changes Locally**:
   ```bash
   npx serve .
   ```
5. **Commit Your Changes**:
   ```bash
   git commit -m "feat: Add support for dynamic two-handed Arabic signs"
   ```
6. **Push to Your Fork and Open a Pull Request**.

---

## 📜 Code Style Guidelines
- Maintain clean, modular JavaScript (ES Modules).
- Comment complex math or vector/quaternion operations in `viewport.js` and `mocap-*.js`.
- Keep CSS variables organized in `style.css`.
